# 营销选人策略线上实验方案（未实施）

## 问题与估计对象

验证有限名额下，使用 Uplift 选人是否比普通购买概率选人带来更多购买客户。比较对象是完整选人策略，不是“是否收到短信”的局部差异。

## 设计

1. 从同一业务周期内符合资格且允许触达的候选客户中，按客户 ID 去重；排除规则事先固定。尽可能避免家庭／账号关联导致跨组干扰；如果必须按家庭、门店等分组随机化，重新按集群设计估算样本量。
2. 候选客户按 1:1 随机分为 Uplift 策略组与 Response 策略组，可按实验前 RFM 档位分层。记录分组概率与固定随机种子；分组之后不因是否成功发送或是否购买而剔除客户。
3. 两组各自按已冻结策略排名，选择约 20% 客户。同分客户按 ID 排序。素材、渠道、发送时段和优惠保持一致；两组客户量相同时使用完全相同的名额。
4. 本方案建议采用发送日起 14 天购买作为待业务确认的观察窗口；这是新实验的拟议口径，不是原数据已确认的窗口。短信送达日志、目标事件延迟与退订流程需在实施前确认。
5. 最后入组的客户观察窗口结束、并经过预先规定的数据到齐等待期后，才进行主分析。不得看到显著结果就提前停止。

## 指标

- 主指标：每组全部随机分配客户中，在固定窗口内至少购买一次的比例。按最初分组进行 ITT 分析；分母不是只有被联系的 20%。
- 主估计：两组购买率之差，报告百分点、每千名候选客户额外购买人数与 95% 区间。若采用分层随机化，使用预先规定的分层加权估计和相应方差。
- 业务次指标：实际触达人数／成功送达率、可归因窗口内的总贡献毛利、人均净收益；只有取得相应数据后才计算。
- 护栏：退订、投诉、发送失败；阈值须在上线前由业务确认，不在缺少历史依据时编造阈值。
- 质量检查：分组比例异常（SRM）、客户 ID 重复、跨组触达、缺失事件、发送时间差异、并行活动污染。出现异常先调查，不以删除异常客户来追求显著性。

## 样本量

`reports/portfolio/tables/experiment_sample_sizes.csv` 给出基线购买率 60%／62%／65%、最小可检测差异 0.3／0.5／0.8 个百分点下的规划值。采用双侧 α=0.05、功效 80%、独立客户、两组等量的两比例正态近似，无连续性校正。

每组人数近似为：

```text
n = ceil((z(0.975)*sqrt(2*p_bar*(1-p_bar))
       + z(0.8)*sqrt(p_A*(1-p_A)+p_B*(1-p_B)))² / (p_B-p_A)²)
```

这些基线率与效应均为规划假设。不要把离线点估计直接当作保证达到的真实效果；样本量不等于触达量，每组实际联系约 20%。具体实验天数需根据每日符合条件的去重客户数、14 天观察窗口和等待期确定，目前无法据数据推算。

固定比例 Top-k 使分配存在容量约束，当前样本量公式是规划近似；正式上线前建议结合实际随机化、分层与批次选人流程做仿真功效评估。

## 预先冻结与决策

冻结模型版本、候选资格、排序规则、容量、指标、窗口、样本量、异常处理和主要比较。最终同时判断效果区间、增量价值与护栏，不单独以 p<0.05 决定推广。若需要判断两种策略相对“完全不营销”的效果，应另设无触达策略组并重新分配样本量；此双组实验只比较两种策略。
