## 状态

已生成 `RetailHero_营销决策_草稿.twb` 和含本地汇总 CSV 的 `.twbx`，完成 XML、数据引用和打包结构检查。**本机没有 Tableau，尚未进行原生打开、画面、参数或筛选交互验证。** XML 可以解析不代表 Tableau 一定可打开；不同版本可能需要重连数据或调整布局。此文件是可继续编辑的草稿，不是已验证或已发布作品。

## 看板结构

| 看板 | 工作表与数据源 | 重点 |
|---|---|---|
| 01 营销效果概览 | overall_rates、test_policy | 全样本购买率描述；已有测试集的五策略收益 |
| 02 策略比较与校准 | test_comparisons、contact_curve、uplift_calibration | 配对差异区间；验证集触达曲线与效果校准 |
| 03 人群与成本情景 | validation_profiles、contact_curve | 选中客户历史消费；成本和毛利参数对应的净收益曲线 |

数据源之间保持独立，不把不同粒度汇总 CSV 直接 JOIN 在一起。比率、效果估计与区间使用 AVG 或 MIN，不能将它们跨策略、跨触达比例或跨数据集 SUM。`contact_share` 为连续维度，曲线每个策略应有 21 个触达比例点。

## 参数与计算字段

参数：假设单客贡献毛利（Margin，默认 30）；假设单次触达成本（ContactCost，默认 0.5）。两者均非负，并使用相同的假设货币单位，不默认代表人民币。

```text
净收益 = [gain_per_1000] * [Margin] - [contacts_per_1000] * [ContactCost]
净收益下限 = [ci_low] * [Margin] - [contacts_per_1000] * [ContactCost]
净收益上限 = [ci_high] * [Margin] - [contacts_per_1000] * [ContactCost]
```

工作簿草稿内参数属于 Parameters 数据源。若控件未自动显示，在 Tableau 中右键相应参数，选择“显示参数”。改变毛利／成本后曲线应随之变化；触达比例为 0 时净收益必须为 0。

配对差异区间图：行放 comparison，列放 AVG(normal_ci_low)，标记为甘特条，大小放 AVG(ci_width)；tooltip 同时显示 estimate_per_1000 和 normal_ci_high。建议在 Tableau 原生编辑时补 0 参考线；不能用两条独立策略区间是否重叠替代配对差异检验。

## 展示边界

- 主结果固定测试集、20% 名额。触达曲线、画像和校准使用验证集，不把两者混合成一个可随意切换的总体值。
- 当前不提供客户人群筛选。只有计算了对应子群的客户贡献及置信区间，才能新增人群效果筛选；不能把全体区间沿用到筛选后的人群。
- Random 为随机选择相同人数的期望，画像是选择概率加权的候选人群画像。
- 所有“收益”以每千名候选客户为分母；成本情景是待验证的假设，不是已实现利润。
- 不在简历中把本草稿写成已经完成 Tableau 原生验证／已发布看板。
